## Severity rubric (normalized, overrides reviewer labels)

- **Critical** — unauthorized spend, seed/PIN/management-key leak that yields spend, or the rightful holder of mnemonic + one committed key + valid PIN cannot recover.
- **High** — factor bypass short of a full spend, production mock driver, recovery that destroys a live key, missing script acceptance on the real network, backup-receipt hole that can freeze funds.
- **Medium** — extra unpublished state required for recovery; isolation gap that does not yet spend.
- **Low / Info** — privacy residual, doc drift, test gap on an otherwise sound path.

Non-Vault capital-safety findings (stranded/resurrected coins, false credit, token loss) are placed on the same scale by fund impact: permanent loss or unauthorized spend of wallet funds → High; loss that needs an unlikely fault or recoverable manual work → Medium.

Invariant codes: **I1** Vault availability, **I2** Vault exclusion, **I3** Vault isolation, **F** general funds safety, **S** secret custody, **A** non-Vault caller/deep-link authorization, **T** token/Mandala asset safety, **P** privacy/SSRF, **D** resource exhaustion.
